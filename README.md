# Car Sales Analysis (Excel Project)

This project analyzes global car brand distribution across countries and decades using Excel.  
The goal is to explore brand popularity trends, regional preferences, and long-term global shifts in the automotive market.

## 📂 Project Structure

car-sales-analysis/
data/ # raw input data (CSV)
excel/ # full Excel workbook with cleaning + pivots + charts
insights/ # final insights in Markdown format


## 📊 Tools Used
- Microsoft Excel (Pivot Tables, Pivot Charts, Cleaning)
- GitHub for versioning & documentation

## 🧹 Data Cleaning Steps

In Excel:
- Checked for blank values
- Removed duplicate rows
- Standardized column names
- Converted date values into decades for trend analysis
- Verified country & brand categories

## 📈 Analysis Performed

The dataset was analyzed from three perspectives:

1. **Global brand dominance**
   - Counted total vehicles per brand (global level)
   - Identified top manufacturers by volume

2. **Country-level preferences**
   - Pivoted counts by country and brand
   - Identified which brands dominate which regions

3. **Historical trends**
   - Grouped manufacturing years into decades
   - Built a line chart to understand brand growth over time

## 🏁 Key Insights (Summary)

- **Ford & Chevrolet** are the most dominant brands globally by volume
- **Toyota** is the strongest non-US brand with major presence in Asia
- China, Indonesia, and Brazil show strong **Ford/Chevrolet** penetration
- Japan shows **domestic loyalty** (Toyota/Nissan)
- USA shows strong preference for **Ford**
- Market shifted from **US dominance (1950–1980)** to **more diversified competition** as Japanese & European brands grew after the 1980s
